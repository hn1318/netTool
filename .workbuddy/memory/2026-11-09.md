# 2026-11-09

## NetTool：后台运行（托盘）+ 关闭行为可配置

### 后端
- `Cargo.toml`：`tauri` 启用 `tray-icon` feature。
- 新增 `src-tauri/src/settings.rs`：`AppSettings { closeBehavior: "ask"|"tray"|"quit" }`，落盘 `{app_data}/settings.json`；命令 `get_app_settings` / `save_app_settings`（非法值回退 ask）。
- `lib.rs`：
  - `setup_tray()`：托盘图标（用 `app.default_window_icon()`）+ 菜单「显示主界面 / 退出」；左键单击显示并聚焦窗口。
  - `on_window_event` 重写：按 `closeBehavior` 分支 —— `tray` 则 `prevent_close()` + `window.hide()` 并写日志；`quit` 则 `cleanup_runtime()` 后正常关闭；`ask` 则 `prevent_close()` + `emit("app-close-request")` 交给前端弹窗。
  - `close_action(action, remember)`：前端弹窗回调；`remember` 时写回设置；`tray` 隐藏窗口，`quit` 走 `cleanup_runtime()` + `app.exit(0)`。
  - 托盘「退出」同样先 `cleanup_runtime()` 再退出，避免 frpc 残留。

### 前端
- `App.vue`：监听 `app-close-request` → 自定义弹窗（取消 / 直接关闭 / 后台运行 + 「记住我的选择」），调用 `closeAction`。
- `Settings.vue`：新增「关闭窗口时」单选卡片（每次询问 / 后台运行 / 直接退出），改动即保存并提示。
- `api.ts` / `types.ts`：`getAppSettings` / `saveAppSettings` / `closeAction` / `onAppCloseRequest` 与 `AppSettings` 类型。

### 实测（PowerShell CloseMainWindow 模拟点关闭按钮）
- `closeBehavior=tray`：窗口关闭后进程仍存活 ✅
- `closeBehavior=quit`：进程退出（exit 0）✅
- `closeBehavior=ask`：关闭被拦截、进程存活等待选择 ✅
- 托盘创建无报错（未打印「托盘初始化失败」）
