# 2026-11-13

## 第四轮：MSL 接入 / 外观自定义 / 通知 / 开机自启动 / 存储位置设置

### 1. 新增 MSL Frp（MSL 幻云）第三方服务
- 参考官方 API 文档（`https://apidoc-user.mslmc.cn/`）与 MSLTeam/MSLX 客户端实现：
  - Base `https://user.mslmc.net/api`，鉴权 `Authorization: Bearer <Token>`
  - `/frp/userInfo`：`name / user_group / maxTunnelCount / outdated`
  - `/frp/nodeList`：节点名称、带宽、协议支持
  - `/frp/getTunnelList`：`id / name / local_port / remote_port / node_id / status`
  - `/frp/getTunnelConfig?id=`：返回 TOML 配置
- 新增 `src-tauri/src/providers/msl.rs`，注册到 `provider_metas` 与四类调度（登录/用户/隧道/配置）；前端自动出现 MSL 卡片（密钥登录，Token 粘贴）。
- `Profiles.vue` 增加 MSL 显示名；`Providers.vue` 增加 MSL 登录提示。

### 2. 外观自定义
- 新增 `src/appearance.ts`：`Appearance { radius, glass, blur, bgImage, bgMask }`，持久化 localStorage，首帧前由 `main.ts` 应用。
- 设置页「外观」：主题、背景图片（FileReader + canvas 压缩到 1920px/JPEG，避免 localStorage 超限）、遮罩浓度、圆角 0–24px、磨砂玻璃开关、模糊强度 0–40px。
- `styles.css`：
  - 调色板整体收敛（更中性的深/浅色、降低霓虹感、统一 `--radius*` 变量）；
  - `html.glass` 下卡片 / 侧栏 / 弹窗 / 输入框使用 `backdrop-filter: blur(var(--glass-blur))` + 半透明底色；
  - `html.has-bg` 支持全屏背景图 + 遮罩。

### 3. 右下角通知
- 新增 `src/composables/toast.ts` + `src/components/ToastHost.vue`：右下角堆叠、类型色、进度条、自动关闭、最多 5 条。
- 接入 Providers（登录/导入/刷新等，watch error/info 统一弹）、Dashboard（连接/断开/重置）、CoreDownload（下载/校验）、Profiles（批量导出/删除）、Tunnels（批量启停/删除、复制 TOML）、Settings（保存/外观/存储）。

### 4. 开机自启动
- `settings.rs` 新增 `get_autostart` / `set_autostart`（Windows 写 `HKCU\...\Run` 的 `NetTool` 值，使用当前 exe 路径）；非 Windows 返回不支持。
- 设置页「启动与关闭」新增开关。

### 5. 存储位置设置（仿截图）
- `AppSettings` 增加 `dataDir` / `logDir`；`settings.json` 固定留在默认配置目录作为引导，数据/日志目录可自定义。
- 新增 `get_storage_info` / `pick_directory`（rfd 原生文件夹对话框）/ `apply_storage_settings`（可选复制迁移现有文件）。
- 启动时 `settings::init_paths()` 锁定本次运行目录，修改后重启生效（避免运行中数据分裂）。
- 日志落盘：`emit_log_event_at` 追加到 `{日志目录}/frpc-YYYY-MM-DD.log`。
- `store::data_dir`、`providers` 凭据路径统一走自定义目录。
